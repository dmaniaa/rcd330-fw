### `opt/launch.sh` & `etc/` Differences
- `5624_vw/opt/launch.sh` comments out `./memtool` register writes and loads `insmod g_iap_ncm_audio.ko`; `5606_skoda/opt/launch.sh` executes `./memtool 0x20c9018=0xffffffff` and `./memtool 0x20c9014=0x10040405`, and loads `insmod g_iap_ncm_eap.ko` (Skoda-only `opt/g_iap_ncm_eap.ko`, `65,057 B`).
- `5624_vw/etc/` includes `Volkswagen-2017-03-06-MIB2-G_Standard+_GP_2017.key` (`1,704 B`), `Volkswagen-2017-03-06-signed-MIB2-G_Standard+_GP_2017.pem` (`3,859 B`), and `ca.pem` (`1,285 B`), absent in `5606_skoda/etc/`.
- Other updated binaries in `5624_vw` vs `5606_skoda`: `opt/connect_mgr` (`55,560` vs `53,028 B`), `opt/iap2d` (`169,152` vs `158,760 B`), `opt/bt` (`680,932` vs `670,404 B`), `opt/AndroidAuto/bin/AAP_Application` (`154,596` vs `147,660 B`), `opt/exlap` (`751,740` vs `750,828 B`), `opt/audio_proc` (`168,636` vs `168,404 B`).

## 4. Skin & Community German Localization Differences

1. **Skin Palette (`gresfiles/` + `VCarMfaPage` tinting)**:
   - `5624_vw` uses red/amber-gold (`0xFFE6BE00` / `0xFFD88000`) and ice-blue (`0xFF1E5AFF`) accents across VW radio/CAR/MFA assets, plus `opt/data/sysupdate_source/VWThesis MQB *.ttf` fonts (`27,696 B` / `27,868 B`).
   - `5606_skoda` replaces UI artwork with Skoda green accents and `SmartLink` branding, and uses slightly older `VWThesis MQB` font subsets (`23,452 B` / `23,600 B`).
2. **In-Place German Language Patch in `5606_skoda`**:
   - Both firmware builds use the compressed 5-language table (`FUN_00023650`):
     - **`5624_vw`** (`ml_start = 0x02d2`, `222` neutral + `1,975` 5-lang entries): `[en_US, zh_CN, pt_BR, ru_RU, es_MX]`.
     - **`5606_skoda`** (`ml_start = 0x02cd`, `219` neutral + `1,961` 5-lang entries): community patchers replaced slot 2 (`Português (BR)`) in-place with **`Deutsch (DE)`**, padding shorter strings with spaces (`"Deutsch (DE)  "`) and `\x1f` backreferences (`\x1f\x01\xde`) so every subsequent string ID byte offset stayed aligned with compiled `.text` callers.
